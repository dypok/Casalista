# CasaLista

Guía y planificador inteligente para pequeñas reparaciones y mejoras en el hogar.

## Características
- Catálogo de reparaciones domésticas organizado en 8 categorías.
- Semáforo de seguridad (Verde, Amarillo y Rojo) para prevención de riesgos.
- Estimación paramétrica de insumos y presupuesto orientativo en Pesos Colombianos (COP).
- Persistencia con SQLite y API REST en FastAPI.
- Vistas renderizadas dinámicas con Jinja2, Tailwind CSS y Google Material Symbols.
